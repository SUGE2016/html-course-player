# 教学课件路线图

## 当前能力

播放器可播放 slides-js 课件并触发课堂互动；课堂服务已有名单文件加载、课次、答题轮次、结果比较、课堂之星和 CSV 导出。教师端仅本机，学生端可显式绑定本机局域网 IPv4。

EduWork 的可选 course_player 插件复用这些能力，通过既有侧栏/外部浏览器打开链接。当前为源码试验，不能等同于完整教学管理产品。

## 第一阶段：完成一次授课

| 功能 | 实施边界 | 验收标准 |
| --- | --- | --- |
| 选课程与教学班 | 明确课程、班级、课次和课件修订的关联；不以聊天会话代替课程身份 | 同课件供不同班级使用，课次记录不混淆 |
| 名单导入 | 复用 roster，增加 CSV/XLSX 字段映射和变更预览 | 重复学号有处理策略，更新名单不破坏历史成绩 |
| 开课加入 | 保留教师/学生端隔离，补加入码、网络入口及错误提示 | 手机扫码加入、提交、教师统计、结束失效实测 |
| 下课导出 | 复用已有 CSV 和轮次记录，补教师入口与课次筛选 | 学号、题目、轮次和成绩与记录一致 |

## Studio 制作与转换

课件制作、PPT 转换、来源与修订管理在 Studio 完成；播放器不另建创作入口。复用现有 Office 检查/转换能力，新增 HTML 课件成果适配后再注册生成技能。

[Studio 课件技能草案](studio-course-authoring/SKILL.md)目前仅作为设计输入，未注册、未接入成果工具、未完成真实 PPT 转换验收。技能要求保留内容和页序、记录动画/对象降级、输出来源映射，并用实际播放器逐页检查。

## 教师本地记录原则（规划约束）

- 点名册、点名/签到记录和课堂表现的权威数据保存在教师设备本地，不存入公开课件、静态 Sites 资源或学生端存储。
- 学生端和未来 Sites 只接收授权的加入、签到或答题提交，不能直接修改名单、出勤结论或历史记录；提交由教师端校验后写入本地，教师纠正须留痕。
- 名单同步只作为导入来源，需由教师确认差异，不能远程覆盖本地历史。公网入口被入侵时，不应因此取得本地记录的任意读写权限。
- 本地存储降低公网服务被入侵后的篡改风险，但不保证教师设备被入侵后仍不可篡改；后续需落实权限隔离、修改审计及可恢复备份，并验证学生端/公网入口无法越权改写记录。

## 后续教学能力

- 点名、签到与教师纠正；不能用“未作答”直接推断缺勤。
- 名单同步通过机构适配器接入，学号作为稳定关联键，删除/转班保留历史。
- 作业创作可以复用 Studio，发布/提交/补交/反馈优先接既有教学平台。
- Sites 公网学生入口与本地监听解耦：部署服务提供真实 URL、HTTPS、课堂访问控制、隔离和撤销；不暴露教师控制端。不通过替换 IP 来假装公网支持。

## 当前限制

尚无课堂加入码，不应将学生端直接暴露到公网；同局域网仍可能受 Wi-Fi 隔离或防火墙影响。临时服务 URL 不是永久成果地址。单人手机试用通过不代表正式班级并发、所有媒体和设备矩阵均已验收。
